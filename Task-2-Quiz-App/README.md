# Task 2 - Online Quiz Maker

This project is part of the CodSoft Internship (Level 2 Task 2).

## Description
An Online Quiz Platform where:
- Users can create quizzes
- Users can take quizzes
- Instant results are shown after completion

## Features
- Quiz Creation (MCQs)
- Quiz Listing
- Take Quiz (one question at a time)
- Score Calculation
- User Authentication
- Mobile Responsive Design

## Technologies Used
- React.js
- Node.js
- Express.js
- MongoDB

Project setup in progress
