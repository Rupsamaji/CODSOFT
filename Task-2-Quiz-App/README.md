# Task 2 — Online Quiz App

A responsive multiple-choice quiz built with HTML, CSS and vanilla JavaScript.

## Features
- Five beginner-friendly web development questions
- One question displayed at a time
- Answer feedback with explanations
- Progress indicator and live score
- Final score with a replay option
- Responsive layout

## Run
Open `index.html` in a modern browser. No installation or dependencies are required.

## Technology
HTML5 · CSS3 · Vanilla JavaScript

## Limitations
This is a browser-only demo with a built-in question set. It does not include account login, a server, database or cloud quiz storage.
