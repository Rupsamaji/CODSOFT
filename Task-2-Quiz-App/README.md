# Task 2 — Online Quiz Maker

## Overview

The goal of this project is to develop an online quiz platform where users can create quizzes, answer multiple-choice questions, and view their scores.

## Planned features

- Create quizzes using multiple-choice questions
- List available quizzes
- Present questions one at a time
- Calculate and display the final score
- Add responsive layouts for mobile and desktop
- Consider user authentication in a future full-stack version

## Technology direction

The original project plan mentions React.js, Node.js, Express.js, and MongoDB. These technologies require an implemented frontend, backend, and database connection before the application can be described as full-stack.

## Current status

Project setup is in progress. The features above describe the intended scope; they are not claims of completed functionality.
